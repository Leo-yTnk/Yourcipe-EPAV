Primary call-to-action button; use for the single most important action on a screen.

```jsx
<Button variant="primary" size="md" onClick={() => save()}>Save Recipe</Button>
```

Variants: `primary` (brand-700 fill), `secondary` (bordered), `ghost` (text-only), `danger` (red-600). Sizes: `sm` / `md` / `lg`. Set `disabled` to grey it out.
